Project: Library

What it is

A training Odoo module for managing a library: tracking books, members, and loan history. Built from scratch to learn the Odoo framework before applying for a Back-end Developer position.

What's inside

  • Three related models: book / member / loan
  • Computed fields: book availability, overdue loans
  • "Lend a Book" wizard for the lending workflow
  • Role-based access: two security groups and record rules
  • Form, list, search and kanban views
  • Constraint validation (can't lend an already-borrowed book)
  • Printable PDF "Reading Card" report per member
  • Unit tests and GitHub Actions CI
